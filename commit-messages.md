# Commit messages

Applies when writing a commit message.

## Rules

- **A message explains why: the reasoning, the trade-offs, the constraints a reader would not guess.** The diff carries the what.
- **No conventional-commit prefixes,** such as `feat:`, `fix:` or `chore(scope):`. A history full of them is not consent to continue. Only an explicit instruction of the project is.
- **A plain `area:` prefix is not a conventional commit.**
